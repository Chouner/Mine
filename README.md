## 关于本站

一个纯静态的个人作品集站点，展示我的工作经历、产品方法论、项目案例和成长路径。

**核心理念**：把领域专家知识转化为可验证的 AI 系统。在声学、核工业、工业检测 3 个完全不同的领域中，验证了同一套产品方法论的跨领域可迁移性。

## 技术栈

- 纯静态 HTML + CSS + JavaScript
- 零框架依赖，单文件架构
- Intersection Observer 滚动动画
- CSS 自定义属性主题系统
- 响应式适配（移动端 + 桌面端）

## 部署

任意静态文件服务器即可部署。推荐：

```bash
# Python
python -m http.server 8080

# Node.js
npx serve .
```
